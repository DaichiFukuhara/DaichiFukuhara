## Favorite Algorithm

```python
start = x          # 配列の先頭の値
increment = a      # 公差
target = ...       # 探したい「値」

L, R = 1, 10**9
ans = -1
while L <= R:                       # < ではなく <=
    m = (L + R) // 2
    val = start + increment * (m - 1)   # インデックス m の中身
    if val < target:
        L = m + 1
    elif val == target:
        ans = m
        break
    else:
        R = m - 1
```
